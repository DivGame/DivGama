# DivGama 🎮

Welcome to DivGama!

## 🎮 Game Features

- Anime-style adventure
- Player movement
- Enemies and battles
- Coins and rewards
- Multiple levels
- Mobile-friendly controls
- Fun gameplay

## 🚀 How to Play

1. Start the game.
2. Move your player.
3. Defeat enemies.
4. Collect coins.
5. Complete the levels.

## 📱 Mobile Game

This game is designed to work on Android mobile devices.
